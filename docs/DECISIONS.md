## Open

* First provinces / programs and the licensed reviewer (T001).
* Payment provider (Stripe Connect?) for earned fees.
* Firms may record their own allowlisted source rows. Hashes are stored, not fetched, until T012.

* `next_review_at` is required to publish and is not calculated from a daily, weekly, or monthly monitoring interval.
* Global drafts stay hidden from tenants. Clients do not see rule claims yet (T017). O01–O15 are not seeded.
* `service_role` can insert a professional review without being that user, because `auth.uid()` is null. That path is trusted infrastructure. T013 must not expose it as a user API.
* Confirm `organizations.age_of_majority_years` default 19, or require the firm to set it before anyone is treated as a minor.
* Firm-owner billing projection is firm-wide and includes applicant display names, while person rows are assignment-only.
* Household membership ids are still visible to the firm owner.
* The live Auth project must have passkeys, and WebAuthn MFA if that factor is used, enabled in the dashboard. This change does not call the live project.
* Login rate limits and idle timeout (T006) are still open.
* If Supabase later allows recovery codes as the only second factor, decide whether app-level codes remain.
