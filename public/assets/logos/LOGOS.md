## 17 Oct 2026: official lockup search (final pass)
Searched for official icon + name lockups for Outlook, Teams, Gmail, Google Calendar and Calendly. None can be used, so the current strip stays: each vendor's own product icon (unaltered), with the product name set beside it in plain text.
- **Gmail, Google Calendar:** Google's Partner Marketing Hub says partners should use plain text ("works with Gmail") and product icons only where necessary, with permission requested through the Hub. Building your own icon + name lockup is not allowed. The Workspace lockups in Google's affiliate brand PDF are for affiliates only. Before launch: request icon permission through partnermarketinghub.withgoogle.com.
- **Outlook, Teams:** Microsoft product icons and names need Microsoft's permission (the "logo check" Francis mentioned). No public lockup files exist. Before launch: Microsoft Trademark and Brand Guidelines, permission request.
- **Calendly:** Calendly rebranded in Aug 2026 (Smith & Diction). The new mark and wordmark have no public brand kit yet. Third-party SVGs (Brandfetch, logo.domains) may show the old mark and grant no rights. Before launch: ask Calendly for the current partner kit.
- The name text uses each vendor's UI font stack (Segoe UI or Google Sans, falling back to Helvetica and Arial). This is the only non-Erode type on the site, and it is there on purpose.
